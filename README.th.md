## สร้างวิดีโอด้วย VideoWeb AI

เปิด [Wan 3.0 บน VideoWeb AI](https://videoweb.ai/model/wan-3-0/) เลือกข้อความหรือภาพ วางพรอมต์ แล้วเลือกการตั้งค่าที่มี เริ่มจากฉากสั้นหนึ่งฉากและเปลี่ยนทีละอย่าง [คู่มือภาษาอังกฤษ](guides/videoweb-workflow.md) · [วิดีโอจาก X](guides/x-community-showcase.md)

## โครงสร้างที่แนะนำ

```text
[ผลลัพธ์] ระยะเวลา + อัตราส่วนภาพ + รูปแบบภาพ
[ตัวแบบ] จุดยึดอัตลักษณ์ที่ใช้ซ้ำ + รายละเอียดที่ห้ามเปลี่ยน
[สภาพแวดล้อม] เวลา + สถานที่ + อากาศ + ชั้นของพื้นที่
[การกระทำ] เหตุเริ่มต้น → การเคลื่อนไหวต่อเนื่อง → ผลลัพธ์ที่มองเห็น
[กล้อง] ขนาดภาพ + มุม + เส้นทางเดียว + เฟรมสุดท้าย
[เสียง] บรรยากาศ + เสียงการกระทำ + ดนตรี + บทพูด
[ข้อจำกัด] สิ่งที่ต้องคงไว้ + ข้อผิดพลาดที่อาจเกิดขึ้น
```

## พรอมต์ทดสอบฉบับเต็ม

```text
8 วินาที, 16:9, ภาพยนตร์สมจริงเป็นธรรมชาติ ยามรุ่งเช้าบนถนนเก่าที่เปียกหลังฝนตก บุรุษไปรษณีย์หนุ่มสวมเสื้อโค้ตสีเขียวเข้มปั่นจักรยานวินเทจผ่านแอ่งน้ำตื้น ล้อหน้าแยกน้ำเป็นละอองต่ำสองด้าน หยดน้ำตกกลับลงบนพื้นหินและไม่ลอยค้าง กล้องติดตามอย่างมั่นคงจากด้านหลังซ้ายที่ระดับเข่า เริ่มด้วยภาพปานกลางให้เห็นถนน จากนั้นเข้าใกล้มือและกระดิ่ง ก่อนยกขึ้นไปยังแสงอุ่นที่ปลายถนน เสียง: ยางผ่านน้ำ ประตูเหล็กร้านค้าที่อยู่ไกล และเสียงกระดิ่งจักรยานหนึ่งครั้ง คงใบหน้า เสื้อโค้ต รูปทรงจักรยาน และทิศทางการเคลื่อนที่ ห้ามมีข้อความ โลโก้ แขนขาเกิน จัมป์คัต หรือวัตถุลอย
```

ดูทั้ง 120 ฉากได้ใน [README ภาษาอังกฤษ](README.md) ความสามารถและการตั้งค่าอาจแตกต่างกันตามแพลตฟอร์มและภูมิภาค

## โปรแกรม Affiliate ของ VideoWeb AI

[ขณะนี้ VideoWeb AI มีโปรแกรม Affiliate](https://videoweb.ai/affiliate-program/) สำหรับนักพัฒนา ครีเอเตอร์ ผู้สอน ผู้รีวิว และทีมที่แนะนำ เครื่องมือสร้างวิดีโอ ภาพ และเพลงด้วย AI เข้าสู่ระบบด้วยบัญชี VideoWeb AI ปกติ กรอกโปรไฟล์และยอมรับข้อตกลง Affiliate จากนั้นสร้างลิงก์แนะนำของตนเองเพื่อแชร์ในบทเรียน รีวิว ชุมชน ผลิตภัณฑ์ หรือเว็บไซต์

- ค่าคอมมิชชัน **20%** จากคำสั่งซื้อแบบชำระเงินที่ถูกต้องครั้งแรกของผู้ใช้ที่แนะนำ
- ค่าคอมมิชชัน **10%** จากคำสั่งซื้อแบบชำระเงินที่ถูกต้องครั้งถัดไปภายใน **ช่วงการระบุแหล่งที่มา 60 วัน** หลังการลงทะเบียน
- การคืนเงิน การเรียกเงินคืน คำสั่งซื้อที่ถูกยกเลิกจากความเสี่ยง สถานะการระบุแหล่งที่มา และการละเมิดนโยบายจะได้รับการตรวจสอบก่อนจ่ายค่าคอมมิชชัน

กฎอาจมีการเปลี่ยนแปลง โปรดตรวจสอบหน้าปัจจุบันและ Affiliate Agreement ก่อนประชาสัมพันธ์ ลิงก์ข้างต้นเป็นหน้าโปรแกรมอย่างเป็นทางการ ไม่ใช่ลิงก์แนะนำของโครงการนี้
