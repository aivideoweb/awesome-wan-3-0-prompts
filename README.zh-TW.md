## 使用 VideoWeb AI 創作

開啟 [VideoWeb AI 的 Wan 3.0 頁面](https://videoweb.ai/model/wan-3-0/)，選擇文字或圖片輸入，貼上提示詞，再依介面選擇設定。先製作一個短鏡頭，每次只改一項。[操作指南（英文）](guides/videoweb-workflow.md) · [X 影片案例](guides/x-community-showcase.md)。

## 提示詞結構

```text
[輸出] 時長 + 畫幅 + 視覺媒介
[主體] 可重複的身份錨點 + 不可改變的細節
[環境] 時間 + 地點 + 天氣 + 空間層次
[動作] 觸發 → 連續過程 → 可見結果
[攝影機] 景別 + 角度 + 單一移動路徑 + 結束構圖
[聲音] 環境音 + 動作音 + 音樂 + 對白
[限制] 必須保持的內容 + 最可能的失敗模式
```
