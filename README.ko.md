[VideoWeb AI의 Wan 3.0](https://videoweb.ai/model/wan-3-0/)에서 텍스트 또는 이미지 입력을 선택하고 프롬프트를 붙여 넣은 뒤 화면의 설정을 고르세요. 짧은 장면 하나부터 시작하고 한 번에 한 항목만 바꾸세요. [사용 안내(영어)](guides/videoweb-workflow.md) · [X 영상 사례](guides/x-community-showcase.md).

## 프롬프트 구조

```text
[출력] 길이 + 화면비 + 시각 매체
[주체] 반복 가능한 정체성 기준 + 변경하면 안 되는 요소
[환경] 시간 + 장소 + 날씨 + 공간의 층
[동작] 계기 → 연속 동작 → 눈에 보이는 결과
[카메라] 샷 크기 + 각도 + 하나의 이동 경로 + 마지막 구도
[사운드] 환경음 + 동작음 + 음악 + 대사
[제약] 반드시 유지할 것 + 가장 가능성 높은 실패
```

## 전체 테스트 프롬프트

```text
8초, 16:9, 자연스러운 시네마틱 실사 영상. 비가 그친 새벽의 오래된 거리에서 짙은 초록색 코트를 입은 젊은 우편배달원이 빈티지 자전거를 타고 얕은 물웅덩이를 지난다. 앞바퀴가 물을 두 개의 낮은 물보라로 가르고, 물방울은 공중에 멈추지 않고 돌바닥으로 떨어진다. 카메라는 왼쪽 뒤 무릎 높이에서 안정적으로 따라가며 환경을 보여 주는 미디엄 숏으로 시작하고, 손과 벨에 가까워진 뒤 거리 끝의 따뜻한 아침빛을 향해 올라간다. 사운드: 물을 가르는 타이어, 멀리서 들리는 가게 셔터, 한 번의 맑은 자전거 벨. 얼굴, 코트, 자전거 구조와 이동 방향을 유지한다. 텍스트, 로고, 추가 팔다리, 점프 컷, 떠다니는 물체 없음.
```

[영문 기본 README](README.md)에서 120개 장면을 탐색할 수 있습니다. 기능과 출력 설정은 지역과 플랫폼에 따라 다를 수 있으므로 현재 사용 중인 인터페이스를 확인하세요.

## VideoWeb AI 제휴 프로그램

[VideoWeb AI는 현재 제휴 프로그램을 제공합니다](https://videoweb.ai/affiliate-program/). AI 영상·이미지·음악 제작 도구를 추천하는 개발자, 크리에이터, 교육자, 리뷰어 및 팀이 참여할 수 있습니다. 일반 VideoWeb AI 계정으로 로그인하고 제휴 프로필과 계약을 완료한 뒤, 본인의 추천 링크를 만들어 튜토리얼, 리뷰, 커뮤니티, 제품 또는 웹사이트에서 공유할 수 있습니다.

- 추천 사용자의 첫 번째 유효 유료 주문에 대해 **20%** 수수료.
- 가입 후 **60일 귀속 기간** 안에 이루어진 후속 유효 유료 주문에 대해 **10%** 수수료.
- 환불, 지불 거절, 위험 취소 주문, 귀속 상태 및 정책 위반은 수수료 지급 전에 검토됩니다.

규칙은 변경될 수 있으므로 홍보 전에 최신 프로그램 페이지와 Affiliate Agreement를 확인하세요. 위 링크는 공식 프로그램 페이지이며 이 프로젝트의 추천 링크가 아닙니다.
