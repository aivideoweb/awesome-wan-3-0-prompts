## Создавайте видео с VideoWeb AI

Откройте [Wan 3.0 на VideoWeb AI](https://videoweb.ai/model/wan-3-0/), выберите текст или изображение, вставьте промпт и задайте доступные параметры. Начните с короткого кадра и меняйте по одному параметру. [Инструкция на английском](guides/videoweb-workflow.md) · [Видео из X](guides/x-community-showcase.md).

## Рекомендуемая структура

```text
[Выход] длительность + соотношение сторон + визуальный формат
[Объект] повторяемые признаки идентичности + неизменные детали
[Среда] время + место + погода + пространственные планы
[Действие] причина → непрерывное движение → видимый результат
[Камера] крупность + угол + один маршрут + финальный кадр
[Звук] атмосфера + шумы + музыка + диалог
[Ограничения] что сохранить + наиболее вероятные ошибки
```

Этот пример предназначен для сравнения формулировок на разных языках. Он ещё не использовался для создания или проверки видео в VideoWeb.

```text
8 секунд, 16:9, натуралистичная кинематографическая съёмка. На рассвете молодой почтальон в тёмно-зелёном пальто едет на винтажном велосипеде по старой улице после дождя и пересекает неглубокую лужу. Переднее колесо разделяет воду на два низких веера; капли падают обратно на каменную мостовую, а не зависают. Камера устойчиво следует сзади слева на высоте колена, начинает со среднего плана улицы, приближается к руке и звонку, затем поднимается к тёплому свету в конце улицы. Звук: шина в воде, далёкая металлическая дверь магазина, один ясный звонок. Сохранить лицо, пальто, геометрию велосипеда и направление движения.
```
