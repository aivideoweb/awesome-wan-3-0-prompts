# Wan 3.0 模型与平台兼容说明

**核对日期：2026-09-22**

本仓库面向用户所称的 Wan 3.0 创作入口，但不把社区传闻或第三方站点文案当作确定规格。Wan 的不同产品、地区和 API 版本可能使用不同的模型名称与功能组合，因此提示词按“能力模块”编写，而不是写死分辨率、最长时长或素材数量。

## 可以安全采用的 Wan 工作流特征

根据 Wan 官方组织、阿里云 Model Studio 视频生成文档和 Wan 系列公开资料，当前 Wan 工作流已经覆盖或出现过以下能力：

- 文本生成视频（T2V）。
- 首图驱动的图生视频（I2V）。
- 参考图片、视频或音频驱动的一致性创作（具体入口与数量依版本而定）。
- 多镜头叙事与声音生成/自动配音（仅部分云端型号或入口）。
- 视频编辑、角色替换、动作驱动等垂直工作流（仅部分型号）。
- Wan 开源系列可作为理解运动、提示扩展和本地工作流的技术参考，但开源型号名称不等同于商业入口的 “Wan 3.0”。

## 本仓库如何适配这些能力

| 提示词内容 | 支持时 | 不支持时如何简化 |
|---|---|---|
| 时间分段与多镜头 | 直接生成完整短片 | 每个时间段单独生成，再在剪辑软件拼接 |
| 身份参考图 | 绑定为人物身份 | 把 3–5 个身份锚点重复到每个镜头 |
| 动作参考视频 | 声明“只参考动作节奏” | 用动作节点和幅度重写为文字 |
| 首尾帧 | 描述中间物理过程 | 使用首图 I2V，并把尾帧作为文字目标 |
| 原生对白/声音 | 指定语言、说话者和声画同步 | 生成无声画面，后期配音与拟音 |
| 视频编辑 | 使用“只改 X，保持 Y” | 从原视频抽取稳定首帧，重新进行 I2V |

## 每次生成前检查平台界面

1. 当前入口是否明确标注 Wan 3.0，而非第三方自行命名？
2. 支持 T2V、I2V、参考生视频还是视频编辑？
3. 时长与画幅由界面设置还是可写入提示词？
4. 是否支持原生音频、上传音频或只有无声视频？
5. 参考素材的类型、数量、大小和权利要求是什么？
6. 是否有地区限制、人物肖像规则或商业使用条款？
