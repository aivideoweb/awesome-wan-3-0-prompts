# 在 VideoWeb AI 生成第一个 Wan 3.0 视频

## 从手里的素材开始

只有想法，选择文字输入；有产品图或人物图，选择图片输入。需要首尾帧时，先确认界面提供两个独立的上传位置。视频编辑、音频参考和多素材参考只有在当前模式提供对应控件时才能使用，不能把其他平台的功能直接套过来。

## 先生成一个短镜头

1. 打开 [VideoWeb AI 的 Wan 3.0 页面](https://videoweb.ai/model/wan-3-0/)。按提示登录，核对当前选中的模型。
2. 下面的例子保持 **Video → Text / Image to Video**，不上传首帧。使用图片时，点击 **Choose Start Frame**，只上传你自己拥有或获得授权的图片。
3. 如果界面支持，打开清晰度、时长与画幅按钮，设置 **10 秒、16:9**，先选较低成本的清晰度。提示词里写时长不能代替界面设置。
4. 粘贴下面的提示词，查看本次费用后生成。声音要求只在当前模式支持声音时生效。
5. 从头到尾看一遍：杯盖是否只打开一次？杯子形状有没有变化？镜头有没有突然切换？蒸汽是否自然上升？
6. 有问题时，每次只改一个地方。例如减小动作幅度、删掉声音要求，或缩短动作。保留前后两版结果以便比较。

```text
10 秒，16:9。一个没有文字的陶瓷随行杯放在窗边木质厨房台面上。摄影机固定在台面高度。0–2 秒，杯盖关闭，杯子静止；2–6 秒，一只成年人的手将铰链杯盖打开一次，然后退出画面；6–10 秒，一缕细蒸汽缓缓上升，杯子继续保持静止。柔和晨光，真实陶瓷纹理。支持声音时：一次轻微的开盖声和安静的室内环境音。保持杯身、杯柄和铰链位置不变。不要文字、商标、多余手指、跳切或物体融化。
```

这是供试用的编辑示例，尚未实测，也不是社区视频的原始提示词。

## 原模板不适配当前界面时怎么办

| 遇到的问题 | 调整办法 |
|---|---|
| 没有 8 秒或 12 秒 | 本次界面提供 5、10、15、20、25、30 秒；选择合适时长后同步调整所有动作时间段 |
| 没有 2.39:1 画幅 | 用可选画幅生成，主体远离边缘，之后再裁切 |
| 多镜头太复杂 | 拆成几个短片，每段重复人物外观，再剪辑拼接 |
| 没有尾帧上传 | 文字描述结尾画面；不要把它当成精确尾帧控制 |
| 没有视频编辑或多参考模式 | 用自有首帧重新生成，或改写成纯文字场景；结果不等于编辑原视频 |
| 没有原生声音 | 先生成画面，后期添加有权使用的配音和音效 |
