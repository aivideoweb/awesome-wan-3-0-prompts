# 动漫、幻想与风格化叙事｜Wan 3.0 Prompts

本分类使用原创视觉语言与原创角色，不依赖现有影视、游戏角色或在世艺术家的个人风格。风格化视频同样需要清楚的空间、动作和材质规则。

## 01｜云海纸鹤门

**模式**：T2V / I2V　**建议**：12 秒，2.39:1

```text
12 秒，2.39:1，原创东方幻想电影，写实山体与克制水墨粒子结合。身份锁定：青年女剑客，长黑发半束，象牙白内袍、靛蓝长外衣、旧银护腕、腰间无纹长剑；脸、发型、服装和剑全程一致。

0–4 秒：黎明云海超广角，她站在狭窄玄武岩桥端，远处第一群纸鹤从右下方逆风进入，衣摆和发丝向左摆动。
4–8 秒：摄影机缓慢推近到全身景，纸鹤绕太阳形成向内收拢的螺旋门；她没有拔剑，只向前迈一步，脚落地时岩面细尘向外散开。
8–12 秒：摄影机轻微升高，螺旋门后的群峰显露，纸鹤保持纸张折痕与统一飞行方向。她抬头，护腕反射一道晨光，画面停在肃静而非爆炸的奇观。

声音：山风、纸翼轻响、远处钟声一次、极轻弦乐。无对白、无文字。不要已有角色、不要法术光束、不要纸鹤变成鸟、不要剑漂浮、不要人物站位跳变。
```

## 02｜墨水鲸穿过图书馆

**模式**：T2V / 首尾帧　**建议**：10 秒，16:9

```text
10 秒，16:9，手绘 2D 动画与纸张纹理。古老圆形图书馆，一名戴圆眼镜、穿芥末黄背带裤的小男孩伏在大地图上睡着。角色采用简洁线条、有限色块和轻微逐帧抖动，但脸部与服装保持一致。

0–3 秒：蓝黑墨水从地图上的海域缓慢聚集，先形成尾鳍，再形成一条半透明鲸鱼；墨水总量连续，不从桌面滴落。
3–7 秒：鲸鱼游离纸面，在书架之间缓慢上升，经过时书页被气流翻动。摄影机以 2D 多层视差向上跟随，前景梯子、中景鲸鱼、后景书架移动速度不同。
7–10 秒：鲸鱼穿过圆顶天窗变成夜空星座，蓝色墨点排列成鲸形；男孩醒来抬头，眼镜反光中出现星座，地图恢复为空白海面。

声音：纸页、柔和水下回声、木结构轻响；无对白。不要 3D 塑料质感、不要真实水淹图书馆、不要改变角色年龄、不要文字或现成角色。
```

## 03｜苔藓机器人照料最后一株花

**模式**：I2V / T2V　**建议**：10 秒，1:1

```text
10 秒，1:1，原创定格动画质感。废弃温室里，一个由旧黄铜盒、两条木质手臂和圆形玻璃眼组成的小机器人，身体覆盖少量苔藓；面前是一株只有两片叶子的白花。机器人结构、苔藓位置和花朵数量保持一致。

0–3 秒：机器人用双手捧起生锈小水壶，关节以可见的逐格节奏转动，玻璃眼内部暖光变亮。
3–7 秒：它缓慢倾斜水壶，只有三滴水落入土壤；第三滴落下后土壤颜色变深，白花从垂下状态轻轻抬起，而不是快速生长。
7–10 秒：温室破窗透入一道晨光，机器人把水壶放回原位，头部向花朵倾斜 10 度；一只纸做的小蛾停在它肩上，玻璃眼眨动一次作为结束。

材料呈现手工木纹、黄铜氧化、羊毛苔藓和指纹感，暖绿与旧金。声音：关节咔嗒、水滴、玻璃温室风声。无对白、无品牌、无机械零件增殖、无突然花海。
```

## 04｜冰原上的光兽约定

**模式**：T2V / R2V　**建议**：15 秒，2.39:1

```text
15 秒，2.39:1，原创高幻想动画电影。身份锁定：16 岁信使，深棕短发、青绿色厚披风、白色毛领、背小皮邮袋；光兽是一只鹿形半透明生物，角像缓慢流动的极光。两者外观全程一致。

0–5 秒：蓝调冰原远景，信使沿冰裂边缘小心前行，远处光兽在风雪中逐渐显形；脚印连续留在身后。
5–10 秒：中景，信使从邮袋取出一枚圆形铜片放在冰面，后退半步。光兽靠近，用鼻尖触碰铜片，接触点出现一圈柔光沿冰裂向外扩散，但冰面不破碎。
10–15 秒：摄影机环绕两者 45 度，暴风雪逐渐减弱，极光角在天空映出通往山口的路线；信使抬头理解方向，光兽转身先走一步，邀请她跟随。

声音：风雪、皮靴压雪、铜片轻响、遥远合唱氛围。无对白。不要已有怪物设计、不要骑乘、不要战斗、不要人体变形、不要让铜片变成武器。
```

## 05｜轨道城的窗户清洁机

**模式**：T2V / I2V　**建议**：8 秒，16:9

```text
8 秒，16:9，明亮复古未来主义 3D 动画。巨大环形太空城内侧，一台橙白色双吸盘窗户清洁机器人沿弧形观景窗工作，机器人有一只方形显示眼和两条短机械臂；结构与颜色不变。

0–3 秒：摄影机在室内跟随机器人横向移动，窗外可见弯曲地平线、农田与倒挂建筑。左吸盘固定，右吸盘向前移动并重新吸附，动作符合交替爬行。
3–6 秒：机器人喷出少量泡沫，用圆形刷头擦出一条清晰弧线；透过干净区域，一艘小型通勤飞船从远处缓慢经过，视差真实。
6–8 秒：机器人发现一块顽固污点，显示眼变成专注的窄线，再用刷头快速擦两下；污点消失，它显示一个简单亮点而非文字。

干净几何、柔和橙蓝配色、可信塑料与金属。声音：吸盘、微电机、泡沫、轻快电子节奏。不要让机器人脱离玻璃、不要无限手臂、不要宇宙爆炸、不要文字或商标。
```

## 06｜纸偶剧场里的龙影

**模式**：首尾帧 / T2V　**建议**：12 秒，4:3

```text
12 秒，4:3，原创纸偶与剪影动画，舞台材质清晰可见。小型木框纸偶剧场中，一个红衣旅行者纸偶站在桥左侧，一只蓝灰色龙形剪影藏在山后；所有角色由可见细杆操控，纸张边缘和关节保持一致。

0–4 秒：暖色背光亮起，旅行者向桥中央移动三小步，每步都是有限关节纸偶动作；山后龙影缓慢升起，看似巨大威胁。
4–8 秒：龙影张口，旅行者举起小盾牌。背光突然侧移，揭示“巨龙”其实是一只很小的蜥蜴纸偶靠近灯源造成的放大影子。
8–12 秒：旅行者放下盾牌，把一张叶子形纸片递给小蜥蜴；蜥蜴叼走叶子，影子也随距离缩小。镜头最后后拉，露出舞台边缘、操偶细杆和观众席一排孩子的剪影。

声音：纸张摩擦、木杆轻响、孩子压低的惊叹与笑声。无对白、无字幕。不要真实动物、不要火焰、不要纸偶变成立体人物、不要隐藏所有操控结构。
```
